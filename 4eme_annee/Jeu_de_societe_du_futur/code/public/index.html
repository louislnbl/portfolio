Règles du jeu "Brain Strom"

Objectif : Être le premier à arriver au centre du plateau !

Déroulement :

  1. Le propriétaire du lobby lance la partie.
  2. Le propriétaire scanne tous les codes ArUco disponibles sur le plateau de jeu.
  3. Les codes sont répartis aléatoirement entre les joueurs.
  4. Chaque joueur voit uniquement ses pions.
  5. Chacun leur tour, les joueurs lancent un dé numéroté de 1 à 3 et déplacent leurs pions ou ceux des autres. Exemple: avec 3, un joueur peut déplacer n'importe quel pion de 3 cases ou 3 pions d'une case.
